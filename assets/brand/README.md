# 여유 아이콘

Open rounded window mark on a soft lavender tile.

| File | Use |
| --- | --- |
| `yeoyu-icon.svg` / `yeoyu-icon.png` | README and marketing (tile + mark) |
| `yeoyu-icon-fg.svg` | Source for the Android adaptive foreground |

Android adaptive/legacy launchers use `@color/yeoyu_icon_background` (`#E9E2F2`) behind `drawable-nodpi/yeoyu_icon.png` (transparent mark). Themed icons use `drawable/yeoyu_icon_mono.xml`. The React sidebar does not render a brand mark.
