# Security policy

## Project status

Yeoyu is an experimental browser proof of concept. It has not received a production security audit and should not be used as the only browser for sensitive accounts or irreplaceable data.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use [GitHub's private vulnerability reporting](https://github.com/loopy-lim/yeoyu/security/advisories/new) and include:

- the affected commit and Android version;
- reproduction steps using non-sensitive fixture data;
- the expected and observed security boundary;
- any relevant crash output with credentials, URLs, tokens, device identifiers, and personal data removed.

If private reporting is unavailable, open a public issue that asks the maintainer to enable a private channel without including vulnerability details.

## Supported versions

There is no supported public release yet. Security fixes apply to the current default branch only. APKs from commits, CI artifacts, or third parties are not official releases.
